ここ最近、証券会社の広告やSNSで「こどもNISA」という言葉を目にする機会が急に増えました。「0歳からNISAが使える」「子どもの教育資金を非課税で」といったフレーズを見て、気になっている方も多いのではないでしょうか。

広告が増えたのには理由があります。2026年10月1日から、主要な証券会社でこどもNISAの口座開設の受付が始まったためです。制度そのものが始まるのは2027年1月で、各社は今まさに口座の獲得を競っています。

ただし、こどもNISAを「子ども版の新NISA」と単純に考えると、誤解しやすい制度です。引き出しのルールや親のお金との関係など、始める前に押さえておきたい点がいくつもあります。

この記事では、次の4点を図表で整理します。

- こどもNISAの基本の仕組みと、18歳以上が使う新NISAとの違い
- 2023年に終わったジュニアNISAから何が変わったのか
- 最も誤解されやすい「12歳ルール」と払出しの仕組み
- 贈与税、親のNISAとの使い分け、口座開設の流れ

本記事の情報は2026年10月3日時点のものです。制度の細部は今後の政省令などで確定する部分もあるため、最新情報は金融庁や各金融機関の公式サイトでご確認ください。

## 先に結論：こどもNISAの要点5つ

1. **0〜17歳の子ども名義で、年60万円・総額600万円まで非課税で積立投資できる制度**。2027年1月に始まる
2. **使えるのは「つみたて投資枠」だけ**。個別株や高配当株は買えず、対象は長期投資向けの一定の投資信託に限られる
3. **お金は原則として引き出せない**。小学6年生の1月以降は引き出せるが、本人の教育費・生活費に使うなどの要件がある
4. **18歳になると大人のNISAへ自動で移行する**。600万円は大人の生涯枠1,800万円の「先取り」で、上乗せではない
5. **口座のお金は子どもの財産**。親や祖父母の入金は贈与にあたり、18歳以降は子ども本人が管理する

「親の資産を増やす裏ワザ」ではなく、「子ども本人の資産を、子ども名義で長く育てる制度」と理解するのが出発点です。

## こどもNISAとは？ 基本の仕組み

こどもNISAは、2026年度（令和8年度）の税制改正で創設された、未成年者向けの非課税投資制度です。これまでNISAは18歳以上しか使えませんでしたが、「つみたて投資枠」の年齢要件を撤廃し、0〜17歳でも使えるようにしました。

税法上の正式名称は「未成年者特定累積投資勘定」で、こどもNISAは通称です。検討段階では「こども支援NISA」とも呼ばれていました。

金融庁は制度の目的を、大学進学など成人後のライフイベントに必要な資金を、長期・安定的な投資で備えられるようにすることと説明しています。

### 図1：こどもNISAの基本スペック

| 項目 | 内容 |
|---|---|
| 開始時期 | 2027年1月 |
| 対象年齢 | 0〜17歳（その年の1月1日時点で18歳未満の人と、その年に生まれた子） |
| 口座の名義 | 子ども本人（運用・管理は親権者等が行う） |
| 使える枠 | つみたて投資枠のみ（成長投資枠はなし） |
| 年間投資枠 | 60万円（月にすると5万円） |
| 非課税保有限度額 | 600万円（買付額ベース） |
| 非課税期間 | 無期限 |
| 対象商品 | 長期の積立・分散投資に適した一定の投資信託 |
| 買い方 | 定時・定額の積立投資のみ |
| 払出し | 原則不可。12歳以降は一定の要件の下で可 |
| 金融機関の変更 | 不可 |
| 18歳以降 | 大人のNISAへ自動で移行 |

出典：金融庁、日本証券業協会の資料をもとに作成

### なぜ今、広告が増えているのか

制度が始まるのは2027年1月ですが、口座開設の受付はすでに始まっています。

### 図2：こどもNISA開始までの流れ

| 時期 | 出来事 |
|---|---|
| 2025年12月 | 令和8年度税制改正大綱に、こどもNISAの創設が盛り込まれる |
| 2026年3月31日 | 関連法が成立し、制度の骨格が確定 |
| 2026年3月31日 | 教育資金の一括贈与の非課税措置が、新規の利用を終了 |
| 2026年10月1日 | SBI証券、楽天証券、マネックス証券などが口座開設の受付を開始 |
| 2027年1月 | 制度開始。口座開設と積立がスタート |

証券会社にとって、こどもNISAは家族単位で顧客を獲得できる機会です。しかも後で説明するとおり、こどもNISAは途中で金融機関を変更できません。最初に選ばれた会社が、その子の口座を長く預かる可能性が高いのです。各社がキャンペーンを打ち出し、広告を強化しているのはこのためです。

## 新NISA（18歳以上）との違い

こどもNISAは、大人が使っている新NISAのつみたて投資枠を、子ども向けに小さくした形になっています。

### 図3：0〜17歳と18歳以上のNISAの比較

| 項目 | こどもNISA（0〜17歳） | 新NISA つみたて投資枠（18歳以上） | 新NISA 成長投資枠（18歳以上） |
|---|---|---|---|
| 年間投資枠 | 60万円 | 120万円 | 240万円 |
| 非課税保有限度額 | 600万円 | 1,800万円（2枠の合計） | うち1,200万円まで |
| 対象商品 | 一定の投資信託 | 一定の投資信託 | 上場株式・投資信託など |
| 買い方 | 積立のみ | 積立のみ | 積立・一括とも可 |
| 払出し | 原則不可（12歳以降は要件付きで可） | 制限なし | 制限なし |
| 金融機関の変更 | 不可 | 可（年単位） | 可（年単位） |

出典：日本証券業協会「未成年者が利用できるNISA」をもとに作成

日本株の個人投資家にとって大事なのは、**こどもNISAでは個別株を買えない**という点です。株主優待のある銘柄や高配当株を、子ども名義のNISAで持つことはできません。投資できるのは、金融庁の基準を満たした長期の積立・分散投資向けの投資信託だけです。

### 600万円は「別枠」ではなく「先取り」

もう一つ誤解されやすいのが、600万円の位置づけです。

こどもNISAの600万円は、大人になってから使える1,800万円に上乗せされる枠ではありません。18歳で大人のNISAに移ると、こどもNISAで使った分は1,800万円の中に数えられます。

たとえば、こどもNISAで600万円分を買い付けて18歳を迎えた場合、大人になってから使える枠は残りの1,200万円です。子ども自身の生涯枠を前倒しで使う仕組みだと考えてください。

## ジュニアNISAとの違い：何が良くなり、何が縮んだか

子ども向けのNISAには、2016年から2023年まで「ジュニアNISA」がありました。こどもNISAはその後継と言われますが、中身はかなり違います。

### 図4：ジュニアNISAとこどもNISAの比較

| 項目 | ジュニアNISA（2016〜2023年） | こどもNISA（2027年〜） |
|---|---|---|
| 年間投資枠 | 80万円 | 60万円 |
| 非課税保有限度額 | 400万円（80万円×5年） | 600万円 |
| 非課税期間 | 5年（18歳まで延長可） | 無期限 |
| 対象商品 | 上場株式・投資信託など | 一定の投資信託のみ |
| 買い方 | 自由（一括も可） | 積立のみ |
| 払出し | 原則18歳まで不可 | 12歳以降は要件付きで可 |
| 大人のNISAとの関係 | 別の口座。資産は移せない | 同じ口座のまま自動で移行 |
| 金融機関の変更 | 不可 | 不可 |

出典：大和総研「2026年度税制改正大綱解説（1）NISA改正（こどもNISA）」などをもとに作成

変更点は「良くなった点」と「縮んだ点」に分けると理解しやすくなります。

**良くなった点**

- 非課税保有限度額が400万円から600万円に拡大
- 非課税期間が最長5年から無期限に
- 12歳以降は、要件を満たせば途中で引き出せるように
- 18歳で大人のNISAにそのまま移行でき、売って買い直す必要がない

**縮んだ点**

- 年間投資枠が80万円から60万円に縮小
- 個別株やETFを自由に選べず、一定の投資信託に限定
- 一括投資ができず、積立のみに

全体として、「長期でコツコツ積み立て、大学進学などに備える」使い方に特化した設計です。

### ジュニアNISAはなぜ広がらなかったのか

ジュニアNISAが2023年末で終わった主な理由は、利用が伸びなかったことです。

### 図5：NISA口座数の比較（2023年3月末時点）

| 制度 | 口座数 |
|---|---|
| 一般NISA | 約1,090万口座 |
| つみたてNISA | 約783万口座 |
| ジュニアNISA | 約99万口座 |

出典：金融庁「NISA口座の利用状況調査」

利用が伸びなかった最大の原因とされるのが、**原則18歳まで引き出せない**というルールでした。途中で引き出すと、それまで非課税だった利益にさかのぼって課税されます。急な出費に対応できないため、多くの家庭が敬遠しました。こどもNISAで「12歳以降の払出し」が認められたのは、この反省を踏まえたものと言えます。

### ジュニアNISAを持っている方へ

ジュニアNISAに残高がある場合、その資産をこどもNISAに移すことはできません。ジュニアNISAの資産は、引き続き18歳になるまで非課税で保有できます。また2024年以降は、口座内の資産をすべて払い出す形であれば、年齢に関係なく非課税で引き出せます。

なお、こどもNISAで資産を売って枠が復活するのは、2027年以降にこどもNISAで買った資産だけです。ジュニアNISAの資産を売っても、こどもNISAの枠は増えません。

## 最重要：「12歳ルール」と払出しの仕組み

こどもNISAで最も誤解されやすいのが、引き出しのルールです。「12歳になれば自由に引き出せる」と紹介されることもありますが、正確ではありません。

### 図6：時期ごとの払出しルール

| 時期 | 払出し | 内容 |
|---|---|---|
| 0歳〜小学6年生の12月 | 原則不可 | 災害などやむを得ない場合に限られ、その場合も口座を廃止して全額を払い出す |
| 小学6年生の1月〜高校3年生の12月 | 要件付きで可 | 本人の教育費・生活費に使うこと、本人が同意していることを書面で示す |
| 高校3年生の1月以降 | 制限なし | 払出しの制限が解除される |

出典：日本証券業協会、大和総研の資料をもとに作成

### 「12歳」は誕生日で決まらない

払出しができるようになる「12歳」は、誕生日で判定するわけではありません。正確には「その年の3月31日時点で12歳以上である年」の1月1日からです。一般的には、**小学6年生の1月**から払出しができるようになると考えてください。同じ学年なら、誕生日に関係なく同じタイミングです。

### 12歳以降の払出しに必要なこと

12歳以降に引き出す場合も、次の要件を満たす必要があります。

- 資金の使い道が、子ども本人のため（入学金や授業料などの教育費、生活費）であること
- 子ども本人が払出しに同意していること
- 親権者などの口座管理者が、上記を示す書類を添えて金融機関に申し出ること

つまり、**親の生活費や住宅ローンの返済に充てることはできません**。あくまで子ども本人のためのお金です。具体的な書類や手続きは、金融機関ごとの案内を確認してください。

### 要件を満たさずに引き出すと課税される

要件を満たさずに払い出すと、口座を開いてから払い出すまでに得た利益（売却益と分配金の累計）に20.315%が課税されます。そのうえで、NISA口座は廃止されます。

損失が出ていた場合も、その損失はなかったものとみなされ、分配金と相殺することはできません。

### 売っても現金は自由に使えない

もう一つ注意したいのは、**口座内で売却することはいつでもできる**のに、その代金を自由に使えない点です。売却代金や分配金は、こどもNISA専用の管理口座で保管されます。この資金は、こどもNISAでの買付にしか使えず、課税口座での株式の購入にも回せません。

「下がりそうだから一度売って、別の口座で運用する」といった使い方はできないということです。

## 18歳になったらどうなる？

子どもが18歳に近づくと、こどもNISAは大人のNISAへ自動的に移行します。手続きは不要です。

移行するのは「その年の1月1日時点で18歳である年」です。このため、同じ学年でも誕生日によって移行の時期が1年ずれます。

### 図7：誕生日による移行時期の違い

| 誕生日 | 払出し制限の解除 | 大人のNISAへの移行 |
|---|---|---|
| 4月2日〜1月2日生まれ | 高校3年生の1月 | 高校3年生の1月 |
| 1月3日〜4月1日生まれ | 高校3年生の1月 | 高校卒業後の1月 |

出典：日本証券業協会「未成年者が利用できるNISA」をもとに作成

※法令上、年齢は誕生日の前日に1つ加わるため、1月2日生まれの方は1月1日に18歳になります。

大人のNISAに移行すると、成長投資枠が使えるようになり、年間投資枠は最大360万円に広がります。金融機関の変更もできるようになります。

同時に、**口座の管理は子ども本人に移ります**。親が積み立ててきたお金を18歳以降どう使うかは、本人が決めることになります。制度を使う前に、家族で考えておきたいポイントです。

## 始める前に知っておきたい実務上の注意点

制度の大枠に加えて、実際に使い始めると気づきやすい注意点を整理します。

### 図8：実務上の注意点チェックリスト

| 注意点 | 内容 |
|---|---|
| 子ども本人のお金でしか買えない | 親や祖父母の口座から直接は買えない。子ども名義の銀行口座や証券口座の資金を使う |
| クレジットカード積立は使えない | 三井住友カード×SBI証券の案内などで、こどもNISAはクレカ積立の対象外とされている |
| 金融機関を変更できない | 18歳未満の間は変更不可。口座を廃止して別の会社で開き直すことはできるが、それまでの利益に課税される |
| 1人1口座 | 同じ子どもが複数の金融機関でこどもNISA口座を持つことはできない |
| 元本保証はない | 投資信託の価格は変動し、元本を割り込むことがある |
| 個別株・株主優待は対象外 | 対象は一定の投資信託のみ |

特に最初の2点は、親自身の新NISAとの大きな違いです。親のNISAではクレカ積立でポイントを貯めている方も多いと思いますが、こどもNISAでは同じやり方はできません。子ども名義の銀行口座を用意し、そこから入金する流れを作る必要があります。

## 贈与税と「名義預金」に注意

こどもNISAの口座は子ども名義なので、親や祖父母が出したお金は、税法上は子どもへの「贈与」にあたります。こどもNISAで非課税になるのは運用益で、入金そのものが非課税になるわけではありません。

### 年60万円なら、ほかの贈与がなければ贈与税はかからない

贈与税には、受け取る人1人につき年110万円の基礎控除があります。こどもNISAの年間投資枠は60万円なので、その年にほかの贈与がなければ贈与税はかかりません。

ただし、基礎控除は**受け取る側（子ども）単位**で計算します。親と祖父母の両方から受け取った場合は合算されます。

### 図9：贈与税がかかるかどうかの目安

| その年に子どもが受け取った贈与 | 合計 | 贈与税 |
|---|---|---|
| こどもNISA用の60万円のみ | 60万円 | かからない |
| こどもNISA用の60万円＋祖父母からの現金50万円 | 110万円 | かからない |
| こどもNISA用の60万円＋祖父母からの現金70万円 | 130万円 | 110万円を超える20万円が課税対象 |

※扶養義務者が、生活費や教育費を必要なつど直接支払う場合は、贈与税の対象外です。

### 「名義預金」とみなされないために

贈与と認められないと、「名義預金」と判断されることがあります。名義預金とは、名義は子どもでも、実質的には親や祖父母の財産とみなされるお金です。この場合、お金を出した人が亡くなったときに、相続税の対象になる可能性があります。

疑われにくくするための主な対策は次の3つです。

1. **贈与契約書を毎年作る**：あげる側ともらう側の合意を記録に残す
2. **毎年その都度判断して贈与する**：「10年間、毎年60万円」とあらかじめ約束すると、600万円をまとめて贈与した（定期贈与）とみなされるおそれがある
3. **子どもに口座の存在を伝える**：理解できる年齢になったら、一緒に運用状況を確認する

なお、祖父母などから最大1,500万円まで非課税で教育資金を渡せた「教育資金の一括贈与」の特例は、2026年3月31日で新規の利用が終わりました。今後は、年110万円の基礎控除の範囲での贈与や、学費を必要なつど支払う形が中心になります。こどもNISAは、その受け皿の一つになると考えられます。

贈与や相続の扱いは、家庭の状況によって変わります。まとまった金額を動かす場合は、税理士などの専門家に相談してください。

## 積立シミュレーション：いくらになる？

こどもNISAで積み立てた場合の目安を試算しました。

### 図10：積立シミュレーション

| ケース | 毎月の積立額 | 期間 | 元本 | 年3%で運用 | 年5%で運用 |
|---|---|---|---|---|---|
| A：10年で枠を使い切る | 5万円 | 10年 | 600万円 | 約700万円 | 約780万円 |
| B：0歳から18年で枠を使い切る | 約2.8万円 | 18年 | 約600万円 | 約797万円 | 約975万円 |
| C：月1万円をコツコツ | 1万円 | 18年 | 216万円 | 約287万円 | 約351万円 |

※筆者試算。毎月積立・月複利で計算し、信託報酬などの手数料は考慮していません。利回りは一定と仮定したもので、将来の運用成果を示すものではありません。

試算から読み取れるのは、**同じ600万円でも、長い期間をかけて積み立てたほうが運用益は大きくなりやすい**ということです。600万円の上限は「買付額」で数えるため、値上がりした分は枠を消費しません。

一方で、すでに年齢が上の子どもは、使える期間が限られます。

### 図11：2027年1月1日時点の年齢別、使える年数と投資額の上限

| 2027年1月1日時点の年齢 | 使える年数 | 投資額の上限 |
|---|---|---|
| 0歳 | 18年 | 600万円 |
| 6歳 | 12年 | 600万円 |
| 10歳 | 8年 | 480万円 |
| 12歳 | 6年 | 360万円 |
| 15歳 | 3年 | 180万円 |

※毎年60万円を満額で積み立てた場合。2027年に生まれた子も、生まれた年から利用できます。

高校生になってから始める場合、使える枠は大きくありません。また、大学入学の直前に相場が下がると、必要な時期に元本を割り込んでいる可能性もあります。使う時期が近いお金ほど、値動きの影響を受けやすい点も意識しておきましょう。

## 親のNISAとどう使い分ける？

子どもの教育資金を準備するなら、親自身の新NISAで運用する方法もあります。両者の違いを整理します。

### 図12：親のNISAとこどもNISAの比較

| 項目 | 親のNISA | こどもNISA |
|---|---|---|
| 資産の持ち主 | 親 | 子ども |
| 年間投資枠 | 最大360万円 | 60万円 |
| 対象商品 | 個別株・ETF・投資信託など | 一定の投資信託のみ |
| 引き出し | いつでも自由 | 12歳までは原則不可、以降も使い道の要件あり |
| クレカ積立 | 証券会社によっては可 | 不可 |
| 贈与税 | 関係しない | 入金は子どもへの贈与 |
| 18歳以降 | 親が管理を続ける | 子どもの大人のNISAに移り、本人が管理 |

使い分けは、次のように考えることができます。

- **親の枠に余裕がある場合**：まず親のNISAで運用するほうが、引き出しや商品選びの自由度は高い
- **親の枠を使い切っている、または使い切る見込みがある場合**：こどもNISAで世帯の非課税枠を広げられる。夫婦がそれぞれ満額を使い、子ども1人がこどもNISAを使えば、世帯で年780万円まで非課税で投資できる
- **祖父母からの援助を子どもの資産として残したい場合**：こどもNISAが受け皿になる
- **子どもに投資を学ばせたい場合**：子ども名義の口座で一緒に値動きを見ることが、金融教育のきっかけになる

反対に、「18歳になったら本人に渡すことに抵抗がある」「小学6年生より前にまとまったお金が必要になりそう」という家庭では、親のNISAで準備するほうが合っている場合もあります。

当サイトでは以前、高配当株とETFの選び方も解説しました。親自身の成長投資枠で日本株を運用する際の参考にしてください（[高配当ETFと個別高配当株、どちらが初心者向き？](/blog/20260921-memo-etf-kobetsu-hikaku/)）。

## 口座開設の流れと金融機関の選び方

こどもNISAの口座開設は、2026年10月1日から各社で受付が始まっています。ただし、実際に投資できるのは2027年1月からです。年内に申し込んでおけば、年明けからスムーズに積立を始められます。

### 口座開設の一般的な流れ

1. **親権者の証券口座を用意する**：多くの証券会社では、親が同じ会社に口座を持っていることが前提
2. **子どもの未成年口座を申し込む**：こどもNISA口座と同時に申し込める会社もある
3. **必要書類を提出する**：子どものマイナンバーと続柄が記載された住民票の写しなど（必要書類は会社によって異なる）
4. **審査を受ける**：証券会社の審査に加えて、税務署の審査がある。楽天証券では、2026年10〜12月に受け付けた分は2027年1月以降に口座が開設される
5. **入金と積立の設定**：子ども名義の銀行口座から入金し、2027年1月から積立を始める

### 金融機関を選ぶときのポイント

こどもNISAは途中で金融機関を変更できません。最初の選択が、18歳までの使い勝手を左右します。

- **取扱商品**：積み立てたい投資信託（全世界株式、S&P500、TOPIX連動など）を扱っているか
- **最低積立額と頻度**：100円から積み立てられる会社もある。毎月・毎日など、積立頻度の選択肢も確認する
- **入金のしやすさ**：子ども名義の銀行口座からの自動入金サービスがあるか
- **管理のしやすさ**：親と子どもの口座を、アプリで切り替えて確認できるか
- **キャンペーン**：各社が特典を用意しているが、あくまで「おまけ」と考え、上の4点を優先する

## よくある質問

**Q1. 祖父母がお金を出して、孫のこどもNISAで積み立てることはできますか？**

できます。ただし、祖父母の口座から直接買うことはできません。いったん孫名義の銀行口座に贈与し、そのお金で買い付ける流れになります。その年に孫が受け取る贈与の合計が110万円を超えると、贈与税がかかる点に注意してください。

**Q2. 兄弟がいる場合、枠はどうなりますか？**

こどもNISAの枠は子ども1人ごとです。兄弟2人なら、それぞれが年60万円・総額600万円の枠を持ちます。口座も1人1口座です。

**Q3. 積立を途中でやめることはできますか？**

積立を止めることはでき、それまでに買った資産は非課税のまま持ち続けられます。課税されるのは、要件を満たさずに口座から資産を払い出した場合です。

**Q4. 中学受験の費用に使えますか？**

払出しができるのは小学6年生の1月以降です。中学の入学金や授業料など本人の教育費であれば、要件を満たして払い出せる可能性があります。ただし、それより前に必要になる塾代などには使えません。

**Q5. ジュニアNISAの資産をこどもNISAに移せますか？**

移せません。ジュニアNISAの資産は、引き続き18歳になるまで非課税で保有できます。

## まとめ

こどもNISAのポイントを振り返ります。

- 2027年1月開始。0〜17歳の子ども名義で、年60万円・総額600万円まで非課税で積立投資できる
- 使えるのはつみたて投資枠のみ。個別株は買えず、一定の投資信託の積立に限られる
- ジュニアNISAより非課税期間・限度額・払出しの柔軟性は改善した一方、年間枠や商品の自由度は縮んだ
- 払出しは小学6年生の1月以降、本人の教育費・生活費などに限って可能。要件外の払出しは課税され、口座も廃止される
- 18歳で大人のNISAに自動で移行し、600万円は生涯枠1,800万円の先取りになる
- 入金は子どもへの贈与にあたる。年110万円の基礎控除と、名義預金のリスクに注意する
- 金融機関は変更できないため、取扱商品や使い勝手を比べて選ぶ

広告では「お得さ」が強調されがちですが、こどもNISAの本質は「子ども自身の資産を、子どもの名義で長く育てる」ことにあります。引き出しの制約や18歳以降の管理まで含めて、家庭の方針に合うかを考えたうえで判断することが大切です。

口座開設の申込はすでに始まっています。気になる方は、まず親自身の証券口座を確認するところから始めてみてください。
