「日経平均は25日移動平均線に上値を抑えられた」「200日線を維持できるかが焦点」。相場のニュースには、こうした言葉が毎日のように登場します。

意味がわからないまま読み飛ばしている方も多いのではないでしょうか。移動平均線は、仕組みさえ知れば、初心者でもニュースの意図を読み取れるようになる道具です。

この記事では、次の3点を整理します。

- 「節目」と呼ばれるものの正体と、移動平均線の仕組み
- 25日線・75日線・200日線の使い分けと、乖離率の目安
- 2026年の相場で、節目が実際にどう機能したか

本記事の情報は2026年9月18日時点のものです。最新情報は各公式サイトをご確認ください。

## 先に結論：長期投資家が見るべき線は、1本か2本で足りる

最初に結論をお伝えします。

1. 移動平均線は「過去一定期間の平均株価」を線でつないだもの。相場の流れをつかむ道具であり、未来を予言する道具ではない
2. 25日線は1か月、75日線は3か月、200日線は約1年の流れを示す
3. 長期で積み立てる方は、200日線と大台の節目を押さえておけば十分。25日線の上下で売買を繰り返すのは逆効果になりやすい
4. 節目は「必ず止まる場所」ではなく、「多くの人が意識している場所」にすぎない

ニュースの言葉を理解することと、それをもとに頻繁に売買することは別です。この記事は前者を目的にしています。

## 「節目」には3つの種類がある

相場で「節目」と呼ばれるものは、大きく3つに分けられます。

### 図1：節目の3つの種類

| 種類 | 具体例 | 意識される理由 |
|---|---|---|
| 大台（心理的節目） | 6万円、7万円 | キリのいい数字は多くの人が目標や警戒ラインにする |
| 移動平均線 | 25日線、75日線、200日線 | 一定期間に買った人の平均的な買値に近く、損益の分かれ目になる |
| 過去の高値・安値 | 6月25日の高値、3月の安値 | その水準で売買した人の記憶が残り、再び反応が出やすい |

この記事の主役は2つ目の移動平均線ですが、3つは組み合わせて語られることが多い点も覚えておいてください。

大台については、2026年は史上まれに見る年でした。日経平均は4月23日に取引時間中で初めて6万円に到達し、4月27日には終値でも6万円台に乗せました。2025年10月の5万円到達からわずか半年での大台替わりで、史上最速です。さらに6月18日には、終値で初めて7万円台に乗せました。

（関連用語：節目、大台、心理的節目）

## 移動平均線とは？ 仕組みは足し算と割り算だけ

移動平均線は、過去の一定期間の終値を平均し、その値を毎日つないだ線です。

25日線なら、直近25営業日の終値を合計して25で割ります。翌日には一番古い1日分が外れ、新しい1日分が加わります。平均をとる期間が「移動」していくので、移動平均線と呼ばれます。

### 図2：3本の線の性格

| | 25日線 | 75日線 | 200日線 |
|---|---|---|---|
| 期間の目安 | 約1か月 | 約3か月 | 約1年 |
| 示す流れ | 短期 | 中期 | 長期 |
| 動き方 | 株価にすぐ反応する | ややゆっくり | 大きな流れだけを映す |
| 主な使われ方 | 目先の支持・抵抗 | 中期トレンドの確認 | 強気・弱気の分かれ目 |
| 向いている人 | 短期売買 | 数か月単位の投資 | 長期投資・積立 |

※期間の分類（短期・中期・長期）は証券会社によって異なります。25日線を「中期」、75日線を「長期」と呼ぶ場合もあります。

期間が短いほど直近の株価に近づき、長いほど大きな流れを示します。この性質を利用して、複数の線を重ねて見るのが基本です。

### なぜ移動平均線が「節目」になるのか

移動平均線は、その期間に買った投資家の平均的な買値に近い水準です。

たとえば株価が25日線の少し上にあるとき、直近1か月に買った人の多くは含み益の状態です。株価が25日線を割り込むと、多くの人が含み損に転じます。「損をする前に売ろう」という動きが出やすくなる一方、「平均的な買値まで下がったから買おう」という動きも出ます。

こうして、多くの人が意識するために、実際に株価が反応しやすくなります。節目が機能する理由は、数学的な根拠というより、参加者の心理にあります。

（関連用語：移動平均線、終値、支持線、抵抗線）

## ニュースの言葉を読み解く

移動平均線がわかると、ニュースの定型句の意味がつかめます。

### 図3：よく使われる表現の意味

| ニュースの表現 | 意味 | 読み取れること |
|---|---|---|
| 25日線が上値を抑えた | 株価が25日線まで戻ったが、超えられずに下落した | 短期の流れはまだ弱い |
| 25日線が下値支持線として機能 | 下落が25日線で止まって反発した | 短期の流れは崩れていない |
| 75日線を回復 | 株価が75日線を上抜けて終えた | 中期の流れが改善した |
| 200日線を割り込んだ | 株価が200日線を下抜けた | 長期の流れに黄信号 |
| 200日線を維持 | 急落しても200日線を割らずに終えた | 長期の上昇トレンドは続いている |
| ゴールデンクロス | 短期線が長期線を下から上に突き抜けた | 上昇に転じたサインとされる |
| デッドクロス | 短期線が長期線を上から下に突き抜けた | 下落に転じたサインとされる |
| 線の並びが交錯 | 短期・中期・長期の上下関係がそろっていない | 方向感が定まりにくい |

理想的な上昇相場では、上から「株価、25日線、75日線、200日線」の順に並びます。下落相場ではその逆です。並びが崩れている局面は、相場が転換点にある可能性を示します。

（関連用語：ゴールデンクロス、デッドクロス、上値抵抗）

## いまの日経平均を3本の線で見る

実際の数値で確認します。2026年9月18日の終値は65,018.95円でした。

### 図4：日経平均と移動平均線の位置関係（2026年9月18日時点）

| | 水準 | 終値との乖離率 | 株価との位置 |
|---|---|---|---|
| 75日線 | 66,640.33円 | −2.4% | 株価より上 |
| 25日線 | 65,466.51円 | −0.7% | 株価より上 |
| 日経平均終値 | 65,018.95円 | ― | ― |
| 200日線 | 59,721.12円 | +8.9% | 株価より下 |

※移動平均線は株式マーケットデータ（出所：日本経済新聞社）の掲載値。乖離率は筆者計算。

株価は25日線と75日線を下回る一方、200日線は大きく上回っています。読み取れるのは次の3点です。

- 短期・中期の流れは弱い。9月に入って株価は25日線の下で推移している
- 長期の流れは上向き。200日線は9月に入っても毎日切り上がっている
- 8月下旬から9月上旬は、25日線を下値、75日線を上値とするレンジで推移する日が目立った

9月1日には、25日線（65,752円）付近が下値支持となる一方、上値は75日線（66,570円）に届かなかったという解説がありました。3本の線が実際に節目として機能した一日です。

3本の傾きも違います。25日線は下向き、75日線は横ばいに近く、200日線は上向きです。傾きの違いは、短期では調整が続き、長期では上昇トレンドが崩れていないことを表しています。

（関連用語：乖離率、トレンド、レンジ相場）

## 乖離率：「離れすぎ」を測るものさし

株価が移動平均線からどれだけ離れているかを、割合で表したものが「移動平均乖離率」です。計算は「（終値−移動平均）÷移動平均×100」です。

株価は移動平均線から離れすぎると、いずれ戻る傾向があります。この性質を使って、買われすぎ・売られすぎを判断します。

### 図5：25日線乖離率の目安（相場の経験則）

| 乖離率 | 一般的な見方 |
|---|---|
| +10%以上 | 天井圏。過熱感が強い |
| +5%以上 | 目先の調整が近い |
| −5%以下 | 目先の反発が近い |
| −10%以下 | 底値圏 |

※野村證券・SMBC日興証券の用語解説に基づく一般的な目安。必ず反転するという意味ではありません。

実例があります。2026年7月29日、日経平均は前日比930円安の61,434円で終え、25日線からの下方乖離率が、2025年4月の関税ショック以来の大きさになりました。日本経済新聞はこれを「売られすぎ」のサインと報じています。6月下旬まで急ピッチで上昇したAI・半導体関連株から資金が流出した局面でした。

200日線との乖離率は、もっと大きな幅で動きます。強い上昇相場では200日線を10%以上上回った状態が続くこともあり、9月18日時点の+8.9%も特別に高い水準ではありません。25日線と同じ目安を当てはめないよう注意が必要です。

乖離率には限界もあります。相場が大きく崩れる局面では、過去の経験則を超えて乖離が広がります。「−5%だから反発するはず」と決めつけて買い向かうのは危険です。

（関連用語：移動平均乖離率、買われすぎ、売られすぎ）

## 2026年の相場で、節目はどう機能したか

理屈だけでは実感がわきません。今年の相場を振り返ると、節目の働きがよくわかります。

### 図6：2026年の主な出来事と節目

| 時期 | 出来事 | 節目との関係 |
|---|---|---|
| 3月 | 中東情勢の悪化で月間13.23%安。3月9日は5.19%安 | 3月31日時点の200日線は47,700円台。終値51,063円は割り込まなかった |
| 4月23日 | 取引時間中に初の6万円到達 | 大台。この日は終値で反落（59,140円） |
| 4月27日 | 終値で初の6万円台（60,537円） | 5万円から半年での史上最速の大台替わり |
| 5月20日 | 6万円を約3週間ぶりに一時割れ | 大台が下値の目安として意識された |
| 6月18日 | 終値で初の7万円台 | 大台 |
| 6月25日 | 高値72,366円 | 以後、この高値が上値の目安に |
| 7月17日 | 終値64,141円。高値から11.4%安 | AI・半導体株の急落 |
| 7月29日 | 終値61,434円 | 25日線乖離率が「売られすぎ」の水準に |
| 8月下旬〜9月 | 25日線と75日線の間で一進一退 | 移動平均線がレンジの上限・下限に |

※日経の指数公式サイト、日本経済新聞、野村證券、みずほ証券の公表情報をもとに作成。

### 3月の急落：200日線が「最後の砦」に

2026年3月は、月間の下落率13.23%、月間値幅6,994円と、過去4番目の大きさでした。中東情勢の悪化で、投資家心理が急速に冷え込んだ局面です。

それでも、月末時点の200日線（47,700円台）は割り込みませんでした。1年の平均を下回らなかったことが、「長期の上昇トレンドは崩れていない」という安心材料になり、その後の反発につながりました。4月には6万円、6月には7万円と、大台を次々に更新しています。

### 大台の壁：6万円は何度も意識された

4月23日に一時6万円に乗せた日、終値は前日比445円安の59,140円でした。大台に到達した直後は、達成感からの売りが出やすくなります。

5月20日には、世界的な金利上昇を受けて6万円を一時割り込みました。大台は上値の壁になるだけでなく、いったん超えると下値の目安に変わります。この「役割の入れ替わり」は、移動平均線にも共通する性質です。

### 節目は「必ず止まる場所」ではない

3月には節目が機能しましたが、そうでない例もあります。7月17日には、高値から11.4%安まで一気に下落しました。上昇が急だった分、25日線や75日線は支持線として十分に機能しませんでした。

節目で止まるのは、多くの人が「ここで止まる」と考えて行動するからです。パニック的な売りが出る局面では、その前提が崩れます。節目は「止まりやすい場所」であって、「止まる場所」ではありません。

（関連用語：史上最高値、調整局面、押し目）

## 初心者がやりがちな3つの誤解

### 誤解1：ゴールデンクロスで買えば儲かる

ゴールデンクロスは、短期線が長期線を下から上に突き抜けることです。上昇のサインとされますが、移動平均線は過去の株価から計算されるため、反応が遅れます。クロスが出たときには、株価がすでに大きく上がっていることが少なくありません。

保ち合い相場では、クロスが頻繁に出ては消える「だまし」も多くなります。クロスのたびに売買を繰り返すと、手数料と税金だけが積み上がります。長期の目安として、3か月以上の視点で使うのが一般的です。

### 誤解2：200日線を割ったら、すぐ売るべき

200日線割れは長期トレンドの黄信号ですが、一時的に割り込んで数日で回復することもあります。終値で割り込んだか、数日続いたか、200日線自体の傾きが下を向いたか。こうした点を合わせて見るのが基本です。

積立投資をしている方にとっては、200日線割れは「売る合図」ではなく、「安く買える時期が来たかもしれない」という見方もできます。売る・売らないは、投資の目的によって変わります。

### 誤解3：節目の数字を当てれば、相場を予測できる

移動平均線も大台も、過去のデータや心理の集積です。未来の株価を決めるのは、企業の業績や金利、海外情勢です。2026年3月の急落を引き起こしたのは中東情勢であり、チャートの形ではありません。

節目は「相場の現在地を知る地図」として使い、「未来を当てる占い」としては使わない。この線引きが大切です。

（関連用語：だまし、保ち合い、積立投資）

## 投資スタイル別：どの線を見ればいいか

### 図7：スタイル別の使い方

| こんな方 | 見る線 | 使い方 |
|---|---|---|
| 毎月積み立てている | 200日線 | 月に一度、株価が200日線の上か下かを確認する程度でよい。売買の判断には使わない |
| 数か月単位で売買する | 75日線・200日線 | 75日線の傾きで中期の流れを確認。200日線割れは慎重になる目安 |
| 短期で売買する | 25日線・乖離率 | 25日線の上下と乖離率で過熱感を見る。損切りのルールを決めておく |
| ニュースを理解したい | 3本すべて | 図3の表現を手がかりに、記者が何を伝えたいかを読み取る |

長期の積立投資であれば、移動平均線を毎日見る必要はありません。むしろ、25日線の上下に一喜一憂して積立をやめてしまうことのほうが、長期の成果を損ねます。

なお、9月末は配当の権利落ちで日経平均が機械的に下がります。権利落ち日の下落は、節目割れとは性質が異なる点にご注意ください。詳しくは[配当権利落ち日は株価にどう影響する？](https://nikkei-note.com/blog/20260922-memo-kenri-ochibi/)で整理しています。

### 移動平均線はどこで見られるか

証券会社の取引ツールやチャート画面では、移動平均線を無料で表示できます。多くのツールでは期間を自由に変更でき、乖離率などの指標も重ねて表示できます。証券口座を開設すると、こうしたチャート機能もあわせて使えるようになります。

## よくある質問

### Q1. なぜ25日・75日・200日なのですか？

営業日ベースで、25日が約1か月、75日が約3か月、200日が約1年に相当するためです。日本では昔から使われてきた組み合わせで、多くの投資家が同じ線を見ていることが、節目として機能する理由にもなっています。米国では50日線・200日線が主流です。

### Q2. 移動平均線は終値で計算するのですか？

はい、通常は終値を使います。終値はその日の売買の結論であり、最も重視される価格だからです。ニュースで「終値で200日線を割り込んだ」と、取引時間中と区別して伝えられるのはこのためです。

### Q3. 週足や月足にも移動平均線はありますか？

あります。週足では13週線（約3か月）、26週線（約半年）、52週線（約1年）、月足では12か月線や24か月線などが使われます。長期投資の方は、日足より週足・月足のほうが大きな流れをつかみやすい面があります。

### Q4. 「一目均衡表」や「ボリンジャーバンド」との違いは？

いずれもチャート分析の道具ですが、移動平均線が最も基本的で、多くの指標の土台になっています。ボリンジャーバンドは移動平均線の上下に値幅の目安を示したもので、移動平均線を理解していれば読み方がわかります。まずは移動平均線から始めるのが順序です。

### Q5. 個別株でも同じ見方ができますか？

できます。ただし、個別株は日経平均より値動きが荒く、決算や材料で節目を無視して動くことが多くなります。乖離率の目安も、日経平均より大きめに見ておく必要があります。

## まとめ

- 移動平均線は「過去一定期間の平均株価」をつないだ線。25日は1か月、75日は3か月、200日は約1年の流れを示す
- 節目が機能するのは、多くの人が意識して行動するから。「止まりやすい場所」であって「必ず止まる場所」ではない
- 2026年9月18日時点で、日経平均は25日線・75日線の下、200日線の上にある。短期は弱く、長期は上向き
- 25日線乖離率は±5%が目先の調整・反発、±10%が天井・底の目安。ただし急落局面では経験則を超えて乖離する
- 2026年3月の急落では200日線が割れず、その後の反発につながった。一方、7月の急落では短期の線は支持線にならなかった
- 長期の積立投資なら、200日線と大台を月に一度確認する程度で十分。25日線の上下で売買を繰り返すのは逆効果になりやすい
